تعليمات رفع المشروع على GitHub Pages

1. افتح مستودعًا عامًا جديدًا (أو استخدم main في مستودع موجود).
2. ارفع محتويات هذا المجلد (الملفات والمجلدات داخله) وليس المجلد نفسه:
   - index.html, sw.js, .nojekyll, README.md
   - center/, teacher/, shared/, vendor/
3. إن لم يظهر .nojekyll في الواجهة (ملف مخفي)، أنشئه يدويًا: Add file → Create new file → Name: .nojekyll → Commit.
4. Settings → Pages → Deploy from a branch → main / root → Save.
5. انتظر ~دقيقة، ثم افتح:
   https://<user>.github.io/<repo>/teacher/
   https://<user>.github.io/<repo>/center/
6. لإصدار تحديث: عدّل BUILD في sw.js، ارفعه، انتظر، ثم أعد تحميل صفحة المعلم.
